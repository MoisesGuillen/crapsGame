# Craps Game 🎲

A command-line Craps game written in C++.

## Features

* Two-dice random rolls using `std::mt19937`
* Uniform 1–6 dice distribution
* Craps point-round gameplay
* Betting and bankroll management
* Win/loss tracking
* Input validation
* Replay functionality
* Final profit/loss calculation

## Build

Requires a C++23-compatible compiler.

```bash
g++ -std=c++23 main.cpp -o craps
./craps
```
